## The joke

> The remote and I have a great relationship. It never argues — it just changes the subject.

The remote changes the channel, and it changes the subject of the conversation — one turn, two readings, no explanation needed.

## How it works

`main.py` (Python standard library only) writes the joke to `/output/entry.txt` and checks it first:

- 1–140 characters (the joke is 90)
- a single line, not only white space
- no leading or trailing white space
- the file on disk reads back byte-identical to the joke in memory

Run it with:

```sh
python3 main.py
```
